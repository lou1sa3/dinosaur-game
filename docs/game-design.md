# Game Design Document

## Game Overview
A 2D endless runner inspired by Chrome Dino.

## Controls
- SPACE: Jump
- DOWN: Duck
- ENTER: Restart

## Game Mechanics
- The dinosaur runs automatically.
- Obstacles appear at random intervals.
- Game speed increases over time.
- A collision ends the game.

## Visual Style
- Minimalist pixel art
- Black and white
- Side-scrolling 2D
